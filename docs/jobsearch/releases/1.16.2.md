## Scope

Full-width list workspaces, collapsible editors, content-sized table columns,
labelled records for narrow containers, bounded filter popovers, and compact
empty dossier sections. Form controls and table actions retain their original
elements and handlers. Breakpoints use the actual available width and height.

External calendar milestones are grouped by application and day, with the
individual timestamps retained in the description. Milestones have no alarm or
busy time; real appointments remain timed. Company and job appear in titles.
Only linked JeMa events can be retired, after replacements were exported
successfully. Existing external events are backed up before modification.
Ownership markers and event revisions are checked. Events with attendees are
not automatically retired. Private Google events are excluded from repair.

The broader pending workflow data migration is NOT included in this release.
The only new runtime table is `google_calendar_event_backups`.
