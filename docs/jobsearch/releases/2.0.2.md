# Release 2.0.2

Datum: 2026-09-04

- Die Jobsuche bietet zwei klar getrennte Wege: Schnellimport für eine oder mehrere bekannte Ausschreibungen sowie profilbasierte KI-Suche.
- Profilbasierte Kriterien sind direkt bearbeitbar und bleiben pro Benutzer erhalten, bis bewusst die Standardwerte aus dem Profil geladen werden.
- Die KI-Ergebnisse erscheinen als Tabelle mit Übernehmen, Match-Prozentzahl samt Begründung, Firma, Arbeitsort, Jobbezeichnung, vierzeiliger Kurzbeschreibung und Link zur Ausschreibung.
- Die Suche arbeitet die ausgewählten Portale weiter ab, bis die gewünschte Anzahl erreicht ist oder alle Quellen ausgeschöpft sind.
- Der Übernehmen-Schritt übergibt nur die geprüfte Anzeige an den Schnellimport; eine Stelle wird nicht automatisch angelegt.
- Der manuelle ChatGPT-Recherche-Prompt ist aus der sichtbaren Jobsuche entfernt.
