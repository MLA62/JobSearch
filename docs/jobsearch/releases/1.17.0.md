## Migration

workflow_calendar_v5 backs up active applications and generated calendar rows before
transactional reconciliation, under an advisory lock. It keeps real follow-up dates,
removes the automatic waiting date equal to submission time, and cancels obsolete
generated completed/closed rows. History is retained. Unknown dates are not invented.
Remote synchronization is blocked if the migration marker is absent.
Google cleanup requires ownership, prior backup, and an ETag check; private imports
and obsolete events with attendees are not automatically cancelled.
