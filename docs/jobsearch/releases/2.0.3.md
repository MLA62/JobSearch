# Release 2.0.3

Datum: 2026-09-04

- Suchkriterien werden beim Eingeben automatisch gespeichert; der separate Speichern-Button entfällt.
- Die KI-Suche zeigt einen blockierenden Fortschrittsdialog, der nur über Abbrechen geschlossen werden kann.
- Ein leerer Suchbegriff wird aus den ausgefüllten Suchkriterien zusammengesetzt.
- Längere KI-Suchen erhalten ein höheres Zeitbudget und liefern bei einem API-Fehler die konkrete HTTP-Fehlerursache.
- KI-Ergebnisse werden in der Benutzersprache angezeigt; Firmen- und Eigennamen bleiben unverändert.
